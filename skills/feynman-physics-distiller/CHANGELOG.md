### 运行时
- **引号纪律（U1）**：归因红线原句"引号原话落不到 ID 就不写引号：可转述并标未核实"改为"引号只给本轮读到的原文并标位置；只落到 ID 则转述加卷章，不写引号"。回审清单第 4 项同步，清单仍是六项。rules/attribution.md 三处对齐：ID 索引脚注；「阅读与引用」补上译文标"译意"、用户粘贴按"你贴的这段"引用、转述加卷章是要求不是禁区；「联网核对」补上 403 时的转述写法。
  - 缘由：ID 证明观点出处，不证明措辞。资料地图只有条目摘要、没有逐字原文，原文站对工具返回 403，所以"带 ID 的引号句"里的字，运行时和评审都核不了。实例：v3 r3 归因-05 交付版第 26 行，把序言条目摘要的中文转写加上引号并标 PREFACE。
  - 原则指向：P10（权威来自出处）、P13（信息在场：没有逐字原文的平面不能判措辞）、本 skill 失败样本 G5 及其近亲、failure_cost F1（洗白引文）/ F2（矫枉过正不再转述）。
  - SKILL.md 4528 → 4576 字节（验收线 4600）。
### 评测层
- **形状代理项改为可推翻的拦截层（U2）**：check_shape 的七个词表代理项（全文无邀请词、全文无回审泄露词、追问无类比引入句、从零首段含目标词、从零末段无新全称结构、直取无类比 / 历史 / 练习词、非物理无菜单问句）命中时判 FLAG，不再判 FAIL。计数 / 结构项仍是机检终审。check_all 的退出码只看 FAIL，RESULT 行写出 FLAG 数。盲评包新增中性的「形状疑点」（命中行 + 它代理的 SKILL.md 契约句，不带判定词），评审者逐条裁定 成立 / 不成立 / 未知，裁定前先过四条疑点校准。单文件臂不评卡，所以它的 FLAG 仍按 FAIL 计。正则常量一字未改。
