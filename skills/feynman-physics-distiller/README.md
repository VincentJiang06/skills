# feynman-physics-distiller（费曼物理蒸馏器）

一对一的中文物理辅导 skill。依据费曼讲义与演讲，从具体问题出发组织讲解；凡说"费曼说过 / 做过"，只认本地资料地图里核验过的出处 ID。

当前版本：3.1.0（见 [CHANGELOG.md](CHANGELOG.md)）

## 什么时候用

- 从零讲一个物理主题（"从零给我讲讲 RC 低通滤波器"）
- 追问上一步（"这里求导我不会，这一步怎么来的？"）
- 只要结果（"只给出导数的数学定义"）
- 伴读讲义（"带我读 I–4 §4–1"）
- 核对归因（"费曼是不是说过…""讲义 I–6 是谁讲的？"）
- 触发词：`$feynman-physics-distiller`

不用于：整门课压成笔记（用 `$vince-course-study`）、非物理问题、费曼生平轶事。

## 结构

- `SKILL.md`：入口契约（五个入口）、回审清单（六项）、归因红线、按需读取表。
- `rules/`：资料地图 `sources.md`（19 个 ID，只有摘要，不含逐字原文）、`attribution.md`（ID 索引与引用规则）、`method.md`、`companion.md`、`conflict.md`、`lineage.md`、`boundaries.md`。
- `docs/`：需求与审计文件（锁定，不改）。

## 3.1.0 要点

- **引号纪律**：引号只给本轮实际读到的原文，并标出位置；只落到 ID 的内容一律转述加卷章，不加引号。ID 证明的是观点出处，不是措辞。
- **形状检查分两层**：计数 / 结构项由机检终审；七个词表代理项命中时只标 FLAG，交盲评者对照契约句裁定，可以被推翻。
- **两臂实验**：回归提示词明确禁止调用 Skill 工具，防止已安装的旧版自动加载。
- **验收**：Opus 5.5 两臂实验 WITH 3 胜 0 负（优势在归因纪律，从零案例还胜在物理条件完整）；battery 1 轮、instance 档，种子命中 4/5，确认 7 条 P3 未修，详见 CHANGELOG。成熟度上限 candidate（异源终评未跑）。

## 安装与公开范围

```bash
npx skills add VincentJiang06/skills --skill feynman-physics-distiller
```

也可把本目录复制到所用 agent 的 skills 目录。需要宿主具备文件读取能力；核对在线原文时使用宿主的网页工具，无需配置专用 API 密钥或安装脚本依赖。文中的 `$vince-course-study` 是作者本机的别名，公开仓库对应 `course-study`。
