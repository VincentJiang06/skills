# 冲突协议：把不一致变成可检验的问题

何时读：直觉与结果或模型与实验冲突 → 读全文

这是本 skill 的教学重建。只有确有冲突时启用；不把每道题演成“直觉大战数学”。费曼式取向的依据是模型应接受实验裁决、直观图像有适用范围，见 [资料地图](sources.md)。

## 先查自己，再诊断对象

先独立复核算式、符号、单位、边界条件和引用范围。若是自己算错，直接改正，不为错误结果构造深刻解释。直觉与公式也可能同时基于不适用的模型，不能预设数学一方代表自然事实。

将冲突写为两个可比较的预测：在同样的制备、操作和读数定义下，A 预测什么，B 预测什么？若两边讨论的不是同一对象，先统一问题。

## 找到发生变化的一步

| 根源 | 应检查的内容 | 有效修复 |
|---|---|---|
| 词或对象换了 | 状态与过程、密度与总量、坐标分量与物理对象 | 固定定义和测量操作，重写双方命题 |
| 参考系或系统边界换了 | 环境交换、外力矩、相对速度 | 画出边界与收支，统一参考系 |
| 计算错误 | 单位、负号、漏项、边界项 | 定位第一个错误，重算其后果 |
| 模型外推 | 线性、低速、弱场、连续介质等前提 | 给出控制参数或反例，恢复遗漏效应 |
| 极限交换 | 求和、积分、微分与取极限的次序 | 写出近似族和两种次序，说明所需条件 |
| 维度或自由度遗漏 | 平面示意是否删掉真实物理信息 | 保留低维表达；必要时解释并补回自由度 |
| 经典图像失效 | 是否硬给量子对象安排经典路径或属性 | 用同一实验的统计预测与形式规则比较 |
| 证据不足或理论未定 | 不同说法是否可被现有数据区分 | 明确现有支持与未解部分，不虚构和解 |

这是检索表，不是排他分类。主因能定位到一个词、条件、操作或漏项，才比“直觉有局限”更有用。

## 选择合适的桥梁

- 有连续极限时构造有限参数族，说清固定什么、改变什么以及在哪种收敛意义下讨论。比较先操作再取极限与相反次序；不能只写一个箭头就声称证明了极限。
- 没有合适的极限族时，用最小反例、收支表、可区分的实验安排或另一种数学表述。量子现象不必被“连续逼近为熟悉经典机制”才能解释。
- 理论与实验冲突时，检查测量方式、统计误差、装置影响和理论预测的适用域；不把实验不符全归于“测量不准”。

例如：每一项趋零不保证无穷多项的和趋零；应检查项数、尾部与收敛条件。单点概率为零也不等于点事件在逻辑上不可能；连续分布的零测度结论不能套给有点质量的分布。这里的例子是数学判别提示，不替代对当前分布的分析。

## 完成标准

指出原先忽略了什么，以及新的判断规则如何改变预测。修复后的规则要能处理一个新情形，并说明尚未解决的部分。问题没有解决就诚实保留，不强行宣布“直觉已升级”。

自然语言帮助把前提和后果说清；严谨的数学步骤可承担证明。目标不是要求学生把全部抽象结构画成熟悉物体，而是让其知道自己在比较什么、为何得出结论、怎样检查。
