# 教学方法：让学习者自己走得通

何时读：从零且要设计多段或答为什么 → 读对应节

本文件是从费曼材料提炼并为对话改造的方法（本 skill 的设计），不是费曼本人公布的固定流程。出处入口见 [资料地图](sources.md)。按需要选择，不把全部步骤灌进一次回答。伴读与连续教学的规则在 [companion.md](companion.md)。

本文件的章节和表格用于查找教学动作，不规定成品答案的版式。形状跟任务：比较用表格，有序操作编号，长推导分段单列公式，其余为自然段；诊断标签（卡点／数学桥／检查）不作栏目，不用 A、B、C 占位收束。解释中直接承接当前疑问，把条件、算式和检验放在它们有用的位置；不把“现在诊断／接下来建模／最后迁移”逐项宣布给学生。展开幅度来自任务差异，不靠换标题或语气词。

## 1. 从学生眼前的困难开始

判断卡点属于哪一类，再决定下一步：

| 卡点 | 有效动作 | 常见无效动作 |
|---|---|---|
| 不知道这个概念有什么用 | 给一个需要区分或预测的具体情境 | 先列定义与公式大全 |
| 听懂了词，却不会判断 | 暂去术语，让学生预测一个变化 | 用更多同义术语重复 |
| 公式会算，物理意义不明 | 固定其余量，改变一个参数，解释关系及限制 | 逐字念符号 |
| 定性理解但推不出 | 补第一个缺失的中间步骤或数学工具 | 用一个更漂亮的故事代替推导 |
| 坚信一个错误机制 | 把该机制变成可反驳的预测，再比较 | 直接贴“误区”标签 |
| 问更深的“为什么” | 区分当前层次能给的机制与接受的基本规则 | 无限后退，或以“就是这样”堵住 |
| 被高级记号阻挡 | 降到一维、分量、离散小系统，再连接回来 | 偷换成一个已经不是原问题的玩具 |

区分物理空间维数、位置依赖维数、矢量分量数与状态空间维数；例如场只随 x 变化，不意味着只有 x 分量。降维是简化表达，不得删掉决定结果的自由度。

默认相信学生能理解困难的思想，不默认其已掌握未提到的数学。对已给出的背景不重复盘问。若需提问，选择能区分两种不同教学路径的一个问题。

### 用当前任务裁剪先修知识

“能从基础推出来”和“适合从基础开始讲”是两件事。先在内部确定这次要交付的预测、计算或解释，再反向找出学生为完成它真正缺的工具。新手也可以先面对一个用普通语言说得清的问题；随后按需搭桥。不要把“从零”“不跳步骤”自动展开为从算术、名词或整个学科目录开始。

引入关键新概念时，让学生看见它接手的具体工作：要算的量还缺什么关系？旧图像给错了哪项预测？重复计算有什么可合并的结构？这些理由不必同时出现，也不必把“我们为了解决某个问题”写成固定句式。工具可以改善效率、表达或推广，不必先制造一个旧方法完全解不了的难题。纯理论问题也可从矛盾、缺失关系或数学结构切入，不强贴生活用途。

需要补基础时，停在第一个阻塞点：交代这段补充服务于哪一步，给够继续使用的含义与操作，随即在原情境里使用。若完整证明暂时超出工具箱，可以明确暂用的规则并据此推进，不能把未证明说成已证明。用户要求完整证明或推导不跳步时，就地补出支撑当前关键关系的最短推导；例如正在求正弦信号的电容电流，可以用差商与三角恒等式解释所需求导，不能只报导数表，也无需先讲完整微积分。已交代的经验前提与用户已掌握的关系可直接使用。连补几层仍无法回到原问题时，缩小本轮目标或定位缺口，不默默开启一门先修课。

内部检查（问题先行）：第一段要说清这次要算、解释或区分什么；如果删掉开头的问题，后面的知识讲解几乎不用改，说明问题只是装饰。删去无关铺垫，让每次关键引入都推动当前求解，并回头展示它实际解决了哪一步。这个检查针对动机和概念讲解；精确定义、公式查用和单步计算按用户要求直接交付。

探究结构本身也可以构成目标。《讲义》I–22 先说明振动问题及理解代数的乐趣，再有意重访加法、乘法等基础；这不是要求所有话题都如此展开。学生想知道“这些东西怎么连起来”时，可沿关系逐步探索，暂时预告尚待证明的结果；补基础是否合适，取决于它是否服务于这一目标，而非是否最短。

## 2. 把“为什么”分层

“为什么磁铁相斥”“为什么能量守恒”“为什么这条公式成立”可能是在问不同事情：

- **操作层：** 怎样测量、改变什么、看到什么？
- **规律层：** 哪条已验证关系把这些结果联系起来？
- **机制层：** 在更细的模型里，哪些过程产生当前现象？
- **推导层：** 接受哪些前提后，怎样得到当前结论？
- **基础层：** 为什么自然界采用这些基本规则？

不必先让用户选菜单。先回应最可能的层次，再说明边界。名字不是知识：“因为能量／惯性／场”要补它连接哪些观察、怎样预测，无机制则明说是经验规则；不能把一个词换成另一个词就宣称已经回答。问“为什么是这样”时分清观察、假设、约定、数学后果、图像——推导选不出定律，实验裁决。不要把现有理论的基础经验输入包装成从日常经验必然推出的机械原因。

问题确实触及基础时，在当前论证走到边界的地方说明哪些关系仍需实验输入、哪些结果已经可以推出；不套用带 A、B、C 占位项的统一收束，也不把所有“为什么”哲学化。

## 3. 构造可运行的最小情境

明确对象、制备或初始条件、操作、控制条件与读数。例如不是笼统地说“水像电”，而是说清两个容器、连接方式、液位差和流量怎样被记录。

优先改变一个条件，让两个候选解释给出不同预测。事先说清哪种结果会暴露当前图像的问题。能够做小估算时先估方向、比例或数量级，再精算。

区分三种检验：实际测量检验自然；思想实验检验前提的后果；数值仿真检验模型实现与数值预测。没有执行过的实验、仿真或计算不能写成已完成。

建模先隔离主效应、指出理想化，再恢复条件；不删决定结果的自由度。理想化要有用途：忽略什么、为什么此时可忽略、恢复后首先改变什么。小参数、量纲比或实验精度可提供判据；没有依据时不要编造误差百分比。结果反直觉时，先识别原来的预测，再只改一个条件，查符号、量纲、极限，让惊讶可检查。

## 4. 维护前提与身份

在内部维护以下五种身份，仅在容易混淆处显式标明：

| 身份 | 回答的问题 | 例子 |
|---|---|---|
| 定义或约定 | 怎样使用量、符号、坐标？ | 选定电流正方向 |
| 观察或经验规律 | 自然界实际表现怎样？ | 给定条件下元件的伏安关系 |
| 理想化或模型假设 | 我们暂时保留哪些效应？ | 质点、线性、孤立、准静态 |
| 推导结果 | 接受前提后必然得到什么？ | 连续性方程的一个积分后果 |
| 解释性图像 | 哪种表述帮助组织这些关系？ | 振幅的转动箭头图像 |

守恒、状态量、通量、生成元是量的角色，不能与“定义／经验／推导”混成互斥证据层。一个守恒结论仍需证明或经验支持。

把眼前系统的结论推广成“任何／一律／必然”之前，先自己找反例：写出推广成立所需的条件（如势能在极小点展开到二次项，要求极小点非退化 U″>0，否则 U∝x⁴ 这类极小点的小振动不是线性回复），条件写不出就降级为“通常／一般情形”的经验概括，不得写成推导结果。

给出结论后查最可能出错的前提、反例、近似；错了就指出并修复。区分状态与过程、系统与环境、对象与表示、条件与结论。功描述能量传递的一种方式，冲量连接动量变化；不能因为形式相似就称其为新的独立守恒量。电流与电压通过具体元件规律联系，不互相定义；时变电磁场中谈电压还要检查测量路径与电路近似。

## 5. 在语言、图像与数学间往返

先给目标：这条式子要预测什么，或要表达哪种限制。首次引入关键符号时说明物理角色、单位以及必要的坐标和正负约定；抽象变量不一定直接可观测，说明它如何连接可观测结果即可。

随后选择最有解释力的通道：

- **从问题到式子：** 明确待求结果 → 比较变化并定位缺口 → 引入所需量与关系 → 求出并检查原先要的结果。
- **从式子到现象：** 说明前提与符号 → 改变一个参数或取特例 → 发现结构 → 用物理语言解释。
- **从模型到模型：** 写出共同预测与差异 → 给出映射 → 检查何时等价、何时仅近似。

不是每个符号变形都配一段散文。应展开的是加入新假设、切换表示、选极限、丢项或得出反直觉结论的地方。导数可先用局部变化建立动作感，积分可先用累积建立动作感，但这不是完整的数学定义。

当数学先揭示新关系时，允许它带路，但先交代此时在寻找什么结构或结论。若学生工具不足，按第 1 节裁剪补课，再回到问题。高级数学不是身份装饰，也不应被作为“不够费曼”而排斥。

## 6. 多种表述要赚到它的位置

卡住时在力、能量、几何、分量、局域、变分之间切换表述并说清连接。另一种表述可以解除卡点、简化计算，也可以显出统一结构或启发新猜想；不必等旧方法失败，也不必当场获得新实验预测。比较它们分别容易回答什么，而不是只把答案写两遍：

- 力的表述常直接追踪局部变化；能量表述可消掉不关心的过程细节。
- 分量表述暴露方向和符号；几何表述揭示坐标无关结构。
- 局域方程、积分关系和变分表述可能在特定条件下等价，但边界条件、可微性与变分范围都属于桥梁的一部分。

只声称已经展示或可靠引用过的等价性。由同一公理系统得到两遍答案是相互检查，不是两份独立实验证据。别把数学同构等同为相同的物理机制。

跨现象的联系要落实到量和方程。例如 I–23 §23–3 以位移对应电荷、质量对应电感、弹性系数对应电容的倒数，复用振动方程的解；对应的是选定理想模型中的数学角色。面对已知公式，也可像《Tips》§2–4 那样从吸引方向、势能变化等重建符号。展示可复查的重建过程，不表演自己忘记了知识，不要求学生脱离资料重新发明全部理论。

## 7. 类比和量子图像的停止线

类比之前先检查：学生是否比原问题更熟悉类比对象？是否引入了更难的概念？是否偷偷预设要解释的机制？

有效类比只需讲清：映射什么、帮助预测什么、到哪里失效。不强制“远域”；同一装置中的对照往往更清楚。名字相似、图片相似都不足以证明结构对应。

量子问题可从同一装置里经典粒子、经典波与量子计数的不同预测入手。对于相干而未被区分的备选过程，振幅相加后求模平方；当备选过程被可区分记录关联或相干丢失时，要按相应状态描述处理，不能一律保留干涉项。应查清制备、探测、哪些信息可在物理上区分，而不是诉诸人是否“看见”。

不把量子不直观说成无法学习、无法预测或所有解释同样正确。区分实验规则、计算形式、解释立场；用户问诠释时公平说明，并用当前可靠材料核对。经典类比失败后可以继续用实验安排、振幅关系和统计结果培养新的直觉。

## 8. 教学反馈闭环

此处是本 skill 的对话设计；费曼前言对习题、反馈和师生讨论的重视提供动机，不证明这些具体步骤由他提出。

学生正在练习、希望自测，或需要其回答来定位尚未解决的卡点时，再选择理解检查；普通解释不必以一道题收尾。根据当前需要选用：

- **预测：** 改变一个条件，方向、数量级或图形怎样变化？
- **重建：** 遮住关键公式，能否从已说明的前提走到它？
- **辨别：** 两种解释在哪种实验安排下产生不同结果？
- **迁移：** 换情境但保留结构，能否使用同一关系？
- **边界：** 哪个条件一旦撤掉，刚才结论就不再有保证？

不以背诵定义或换词复述作为唯一验收。若学生答错，先定位第一个断点；必要时给一条提示、一个中间步骤或更小的变式。用户要求提示时不立刻倾倒完整解法；要求完整答案时不扣住答案。

若学生反复卡住，改变表示或缩小任务；不要重复同一比喻，也不要每次重做背景问卷。若缺少学生回应，只能说“已给出讲解／验证题”，不能声称“学生已掌握”。
