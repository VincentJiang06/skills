# 概念谱系与横向比较

何时读：要概念来源、发展史或比较 → 读全文

这是一种辅助研究镜头，由本 skill 组织（本 skill 的设计），并非费曼本人命名的横纵分析法。不在每次物理问答中强制使用。只有用户要概念来源、发展史、系统比较，或相邻概念的混淆阻碍理解时展开。

## 纵向：两条不同的线

**历史线**回答：当时是什么问题、哪些人作了什么测量或提出什么想法、后来怎样修正？必须以原始文献或可靠史料为依据。合理的课堂故事不等于真实发现史。

**逻辑线**回答：从今天选定的出发点，接受哪些定义、经验输入、近似和数学条件，能重建什么？可以改变讲述次序，不必从人类认识史的第一步开始。要明确这是现代重建，而不是声称当事人沿这条路发现。

只有与问题有关时才追溯：测量需求 → 概念或记号 → 新的经验内容 → 可推导结果 → 推广与边界。这不是每个概念必走的单线；有些结构先由数学出现，有些经验输入暂时不能从已知理论推出。

## 横向：选真正有区分力的参照

选择一两个足够解除混淆的比较对象；更多参照仅在系统研究时使用。

| 比较角度 | 检查什么 |
|---|---|
| 对象与角色 | 状态量、过程量、密度、通量、表示或生成元是否混淆？ |
| 条件与关系 | 两个量由定义相连，还是需独立动力学或材料关系？ |
| 空间与维数 | 物理空间、位置依赖维数、分量数、状态空间是否被混称“维度”？ |
| 测量与预测 | 它们分别对应哪些操作或参与哪些可观测结果？ |
| 守恒与收支 | 对哪个系统、什么条件成立；源项或交换是什么？ |
| 表述与等价 | 同一对象的不同表述，还是仅有相似的数学结构？ |
| 推广边界 | 变换模型、尺度或自由度后，什么不再成立？ |

例如角动量与力矩，应指明参考点，并比较状态描述与变化来源；不能只说成“有没有绕圈”。动量与动能的比较需说明方向信息、参考系与所用动力学。电流与电压的联系需要元件及电磁近似，不能靠水流类比互相定义。

## 交叉结果必须回答原问题

有价值的结果可能是：一种早期近似怎样导致今天的误解；两个相似量为什么承担不同角色；换一种表述可以预测什么；哪段逻辑其实偷偷用了额外经验。

只有来源足够时才给历史因果判断，并区分文献事实与自己的综合。没有新的交叉发现就直接给清楚的比较，不凑洞察数量。不强制表格、PDF、报告长度，也不重新开启诊断轮。所有文献与归因按 [归因规则](attribution.md) 处理。
