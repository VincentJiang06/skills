# course-study

> 跟着老师的节奏一讲一讲伴读：把这一讲讲透、标清考试怎么考，并把新知识落进课程记忆库。

[English](README.en.md) · **v4.4 三个档位** —— 默认“详细 PPT 解释”展开每页逻辑与原例题；“完全代替讲课 / 只用 PPT 思路”选择自足慢讲，沿原方法和顺序在正文补先修与中间推理；“作业详细解析”独立按原题号逐小问写已知、代入、计算、答案和验算。提示版保持独立，不因要求更详细就泄露答案。

档 3 明确数据版本、符号维度、求和/平均、初值、阈值、舍入和前问依赖，不能用理论综述或库调用替代实际做题。档 2 不用外部捷径替换 PPT 方法。三个档位都按真实覆盖、可复算性与来源验收，不以字数判质量。规则见 [讲义档位](rules/lecture-modes.md) 与 [作业解析](rules/worked-solutions.md)；以下 v4.2 测评记录为历史结果，并非 v4.4 测试结论。

**简体中文**

**做什么** —— 拿到一讲讲义，写一份顺着讲义原有顺序的中文伴读文档（平铺在课程文件夹的 `study/` 下；已有 `study/伴读/` 的旧课程沿用原目录），同时把这讲的新知识追加进 `study/记忆库/`，让下一讲能正确接上前文；期末再从记忆库统一总结。

**好在哪** ——
- **顺老师的顺序讲**：每 1–3 页一节，标题带页码区间，每个内容页都有专门的讲解段落；节与页的先后不动。
- **写给第一次学这页、没去听课的人（4.2）**：每节先用白话说这页在解决什么，再逐个拆符号、把每一步「为什么」接上，凡有公式或过程必带一个用具体数字走到底的小例子；宁长勿省，只不许复述 PPT 和说空话。不设字数门。
- **适量示意图（4.2）**：状态机、算法逐步状态、数据流这类「一张图比一段话清楚」的地方，会画 mermaid 或 ASCII 示意图，图前标明「我画的，非讲义原图」，图里的每个元素都来自讲义该页；PDF 导出时 mermaid 保留为代码块。
- **例题带原题（4.2）**：讲任何一道题（讲义例题、作业题、往年卷题）之前先逐字抄题面——数据表、选项、分值都在，图片化的表视觉读取并标注——不用再去翻题目 PDF。
- **文件头讲定位，证据放文末（4.2）**：开头五行说清哪门课、哪一讲第几部分、对应原件哪些页、这份讲什么、前后是哪份；「考试证据」清单移到文末 `## 来源与证据`。
- **附录可点（4.2）**：主体每处「见附录 An」是同文件链接，附录每节末尾有「回到正文」；GitHub 的渲染输出与 Typora 的源码都支持这种写法，但两处都没做过点击实测；Obsidian、pandoc 导出本机未装、未测——所以链接文字本身写成读得通的，不跳也不丢信息。附录还可以放前置知识速补、符号表、多一个算例、易错对照。
- **服从课程文件夹自己的规矩（4.2）**：课程根有 `SPEC.md` / `AGENTS.md` 时先读，只在文件放哪、叫什么、相对链接怎么写、写完跑什么这四件事上服从；会限制内容的条款不执行并报告。4.2.1 起分拣规则明确为这两份开例外：读任何 PDF 之前先读、不列进「未读」；课程根其余 markdown 仍不读。
- **图没核对会单独告诉你（4.2.1）**：某页的结构图或整页位图渲染不出来时，那一节写明「未能核对」，回复里另起一行「图形未核对：<文件> p.N（原因）」；文末那行考试证据不受影响。
- **原话是锚**：`> **p.N** 原文` 逐字引用，讲解跟在引用之后；讲义没说的一律写进「**补充**：」，与讲义内容分得开。
- **每个知识点三问**：它是什么 / 为什么是这样 / 考试怎么考。讲义抛出没答的问题算完、只给结论的推导补齐；档 1 的长推导可进带回链**附录**；档 2 必需过程留主线，档 3 过程留对应小问。
- **公式写法从严**：只用 `$…$` 与独占行的 `$$`，公式内全 ASCII、不出现 `|` 与 `*`，标题与文件头不写公式，每条都要过 KaTeX——为的是同一份 `.md` 在 Typora / GitHub / Obsidian 都渲染得出来（Typora 需在「偏好设置 → Markdown」里勾选「内联公式」）。
- **考试角度带证据分级**：A（往年卷 / 作业里真出现过，写文件名与题号）· B（大纲或讲义自述）· C（通识，只能写「常见考法是……」）；任何级别都不写「必考」。
- **课程记忆库可冷重启**：索引一行一个概念（出处页码、一句话、状态），只追加不重写；新会话只读索引 + 本讲 PDF 就能正确引用前文——后一讲修正前一讲时，修正后的结论**回写成索引里的一行修正行**，所以索引始终自足。
- **原有入口（继续支持）**：跟课（默认）· 追问已入库概念 · 期末总结 · 跨讲重排。
- 中文讲解、术语保留英文原词（考试是英文）；markdown 为主，PDF 可选导出（固定模板，只求文字都能看到）。

**已知局限（4.2）** —— 很长的一讲一次可能只写完前面的 Part：导航里会标「（未写）」，回复会说写到哪，下次给同一讲接着写。往年作业 / 试卷的同型题在附录里是完整演练（含结果），v4.4 的独立题解则按小问在正文讲全，不自动提交。附录链接的点击跳转在 GitHub / Typora 未做实测，mermaid 在 GitHub / Obsidian / pandoc 未实测。少数规则靠模型自觉执行、偶有遗漏（【延伸】与记忆库回写的对应、条目英文原词、「（未核）」标注），没有机械门兜底。开发期扫描器只判形状不判内容，讲透没有只由盲评判；粒度门的「动画分页」豁免（4.2.1 起）要求首行相同、每页抽得到页脚逻辑页号且区间最多跨 3 个逻辑页，不核内容是否逐张递增；页脚号只从每页最后一行抽，末行恰是正文数字时会误认（已知一例假绿），跨 2–3 个逻辑页的错标也放过。对裸模型的对照（4.2.1，3 例）：可学性与正确性三例全平，忠实度（文件头、逐字题面、附录回链、记忆库）三例都更好，但篇幅是裸模型的 2–3 倍，主要多在「引一句 PPT、再复述一遍」，注水维三例输两例、平一例。

**什么时候用** —— 「这是 lecture 9，给它写伴读并入库」·「给这个 PPT 写辅助文档」·「所以 lw 的关键路径为什么长 1ns？」（就已入库概念追问）·「期末了，把整门课总结一下」；也可 `$course-study` 显式调用。

**边界** —— 详细解析可逐问给最终答案与验算；只要提示时不泄露答案。不自动修改正式提交文件或提交作业，不把非官方笔记当事实来源。物理题的费曼式讲解归 feynman-physics-distiller；间隔重复与 Anki 导出不在本技能内。

**其他入口** —— 保留概念追问、期末总结、跨讲重组；v4.3 起支持用户指定范围的批量深化、逐篇覆盖核验与备份安装。没有 Phase-0 问卷，不按页数机械分档。
