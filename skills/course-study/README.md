# course-study

> 跟着老师的节奏一讲一讲伴读：把这一讲讲透、标清考试怎么考，并把新知识落进课程记忆库。

[English](README.en.md) · **简体中文**

**做什么** —— 拿到一讲讲义，写一份顺着讲义原有顺序的中文伴读文档（放进课程文件夹的 `study/伴读/`），同时把这讲的新知识追加进 `study/记忆库/`，让下一讲能正确接上前文；期末再从记忆库统一总结。

**好在哪** ——
- **顺老师的顺序讲**：每 1–3 页一节，标题带页码区间，每个内容页都有专门的讲解段落；节与页的先后不动。
- **原话是锚**：`> **p.N** 原文` 逐字引用，讲解跟在引用之后；讲义没说的一律写进「**补充**：」，与讲义内容分得开。
- **每个知识点三问**：它是什么 / 为什么是这样 / 考试怎么考。讲义抛出没答的问题算完、只给结论的推导补齐；完整推导与完整算例进**附录**，主体保证读得顺。
- **公式写法从严**：只用 `$…$` 与独占行的 `$$`，公式内全 ASCII、不出现 `|` 与 `*`，标题与文件头不写公式，每条都要过 KaTeX——为的是同一份 `.md` 在 Typora / GitHub / Obsidian 都渲染得出来（Typora 需在「偏好设置 → Markdown」里勾选「内联公式」）。
- **考试角度带证据分级**：A（往年卷 / 作业里真出现过，写文件名与题号）· B（大纲或讲义自述）· C（通识，只能写「常见考法是……」）；任何级别都不写「必考」。
- **课程记忆库可冷重启**：索引一行一个概念（出处页码、一句话、状态），只追加不重写；新会话只读索引 + 本讲 PDF 就能正确引用前文——后一讲修正前一讲时，修正后的结论**回写成索引里的一行修正行**，所以索引始终自足。
- **四个入口**：跟课（默认）· 追问已入库概念 · 期末总结 · 跨讲重排。
- 中文讲解、术语保留英文原词（考试是英文）；markdown 为主，PDF 可选导出（固定模板，只求文字都能看到）。

**什么时候用** —— 「这是 lecture 9，给它写伴读并入库」·「给这个 PPT 写辅助文档」·「所以 lw 的关键路径为什么长 1ns？」（就已入库概念追问）·「期末了，把整门课总结一下」；也可 `$course-study` 显式调用。

**不适用** —— 代写要提交的作业答卷（同型题只在附录里演练，并写明来源文件与题号）；物理题的费曼式讲解（→ feynman-physics-distiller）；刷题 / 间隔重复 / Anki 导出 / 互动测验；非官方的既有笔记（只读官方讲义）。
