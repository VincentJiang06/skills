何时读：新写或深化课程笔记时全文读；用户说“全部更新”时先执行逐篇盘点，不只交示范。它补充原有来源、顺序、页码、附录和记忆库规则；渐进解释、自测及验证的要求以本文件为准。

# 让读者凭笔记理解

## 先确认范围与来源

- 只盘点用户指定课程和目录。逐文件区分学术伴读、Tutorial/Lab、学术答案解析、提示版本、阅读导航，以及行政、记忆库、核验记录、缓存；后三类不混成课程正文。
- 记录每篇文件名、来源原件、页/幻灯片范围、版本/年份、适用课程与 ESTR 等进阶边界。找不到原件时标“来源未重新核对”，保留已知出处，不宣称已读或用常识补造引用。PPTX 用幻灯片序号，PDF 用物理页号；转换后核页数和对应关系，不能混用编号。
- 读取既有全文与有关原件，建立私有覆盖表：原主题、定义、公式、例题数据、图表、结论、未解问题、旧标题/锚点，对应新稿位置与实际补充。先备份并记源文件哈希；staging 完成后确认源未被别人改动再安装，不覆盖并发修改。
- 阅读顺序沿原讲义；新增先修回顾只补当节必需知识并标补充，不用重新排序伪装完整。当前、历史预习、进阶专属分开标；旧考核比例、截止日期、软件行为不能自动继承到本学期。

## 用可理解的递进代替扩字

先让读者知道问题是什么、为什么需要这一节、已有办法缺什么。指出最低先修知识并就地解释用得到的部分，不假定读者刚读过上一讲。先给具体情境或直观例子，再引入术语和符号，最后给一般形式；受原讲义顺序约束时在本节内完成这条递进。

首次术语给中文含义及必要英文，符号给类型、维度、范围和单位。每一步写清输入、操作、理由与结果；展开实际卡点，避免“显然”“同理”掩盖关键推理。区分定义、假设、推导结果、近似、经验观察与补充。条件在使用前说明，后面用反例或失败情形解释为什么需要。

保留原有核心题目与数据，完整走到结果并解释结果意味着什么。自取例子当场标明，不能用更容易的新例子替换原来的难例。概念用辨析、程序用执行轨迹、历史用证据论证，不机械要求每节都有数字。只有确实有帮助时才加图、表或附录；长推导的正文保留关键链路和跳转，附录给逐步过程及回链。

每一新增段落都应解决该篇具体的理解障碍。不能给所有文件粘贴同一前言、符号表、学习建议或自测来冒充更新；不能用字数增长、文件时间或代理启动数当完成证据。已优质篇目先逐篇查缺，再补局部条件、执行过程、反例或解释；保留已核推导，不为制造差异无意义改写。仍无实质缺口时如实记录已复核及证据，不伪造改进。

按 rules/subjects.md 选学科重心：数学/算法重证明条件与可复算实例；编程重执行、资源生命周期和调试；人文重背景、概念、论点与证据的距离和史料限度。

## 自测与提示

自测针对本节真实卡点，可用“用自己的话解释”“换数据重做”“找反例”“跟踪执行”“用材料支持或反驳一个解释”。自编题明确标“自测（自编，非原题）”，不加虚构页码或 A/B 级证据；不为每个小标题强塞题。

答案按需要分为方向提示、关键步骤、完整解释与检验，默认关闭。优先使用目标渲染器已有的折叠语法（例如支持该扩展的网站用 `:::hint` 与 `:::endhint`，先查看其具体参数和嵌套规则）；仅确认 HTML 不会被转义或过滤时才用无脚本的 `<details><summary>…</summary>…</details>`。实际验证默认状态、键盘展开和块内公式。纯 Markdown 环境用明确的答案段与跳转，不假称默认隐藏。

独立 HW 提示版本只逐级搭桥，不在标题、摘要、旁注、导航摘要、下一篇预览中泄露最终数值、闭式结果或完整解法。完整解析另页、明确入口后才阅读；若用户只要提示，不擅自生成完整答案。已授权学术答案解析可讲全并验算，但不改正式提交文件、不自动提交。

## 验收：结构通过还不够

1. **逐篇覆盖**：对旧稿及实际源页逐项核对主题、例题、图表、条件、当前/历史标注。每篇记录具体补了什么、核了什么及待核项；抽样只用于独立复核，不能代替全量覆盖。原题遗漏、推导被摘要替换、只加通用段落均退回修改。
2. **学科正确性**：数学检查维度、符号、定义域、量词、必要/充分条件、边界、单位与舍入；完整重算新增或改动例题，对高风险梯度/概率/矩阵结论用独立手算、数值或符号检查交叉验证。算法跟踪每步状态并核不变量；程序核环境、异常/并发路径，运行安全的最小例子并区分预期与实际输出；人文核年代、引文、因果桥梁与证据适用范围。数值符合不等于一般证明成立。
3. **实际渲染与链接**：通过真正的 Markdown 解析和 KaTeX 错误检查；检查每个内部文件、图片依赖及目标锚点（含中文、空格、跨文档链接和旧 URL）。如有网站，实际浏览桌面及手机，检查长公式、表格、代码块、导航和折叠答案，不只跑构建。
4. **来源诚实**：实际读过、只抽取文字、视觉核对、未读/无法核对分别记录。教材或网页必须实际访问相关内容后才作为核验来源；编程未运行、数据缺失、推导未独立验证要如实说明。不要用“所有人完全理解”作无法验证的保证；报告读者现在能完成哪些具体任务。
5. **安装与发布**：有授权才同步源文件与网站。只同步指定学术 Markdown 和必要获准资产；原 PPT/PDF/notebook、整套截图、记忆库、日志、配置、个人路径、凭证与原始作业附件不公开。原课件链接在网站标为本地资料，不伪造地址。保留稳定路径和对应位置的旧锚点。部署必须等精确提交 SHA 的 CI 成功，再核公开页面；构建通过不等于上线。

验证记录、覆盖表、备份与内部工作流程留在非公开工作区。对用户交付实际文件清单、逐课程/逐篇改进证据、执行过的检查及结果、仍未核事项；只在已完成时说完成。
