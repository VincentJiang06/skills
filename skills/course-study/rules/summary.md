# 总结与重排

## 总结入口

从记忆库 + 各讲伴读（`study/` 根层与旧课程的 `study/伴读/` 两处都认）出发，写 `study/复习笔记.md`（位置、H1 与跨文件链接按 rules/layout.md）；不重读全部 PDF（除非记忆库缺该讲且用户明说「缺的也一起做」——那先按跟课逐讲入库再总结）。不改动任何已有伴读与记忆库文件。

先读 `索引.md` 文件头与全部条目行，再按需读 `L{nn}.md` 与各讲伴读。缺讲（索引「已处理讲次」只有 L01–L03、L10）→ 报告缺哪几讲，照写文件，文件头一行「覆盖范围：L01–L03、L10；缺 L04–L09（记忆库无此讲，未编）」，对账以已有条目为分母（D8 候选 A）。

### 复习笔记形状

```markdown
# <课程代号> 复习笔记
修正过的条目：1 条（#L13-06 已被 L14 p.4 修正）
覆盖范围：L01–L15

## L09 流水线
### 结构冒险（#L09-04，L09 p.17–20）
一句话：…                      ← capsule，先用人话说它是什么
直觉：…                        ← 为什么有它、解决什么问题
形式：…                        ← 公式 / 定义的精确版，符号定义
算例：…                        ← 讲义里的算例结论与关键一步
联系与误区：…                  ← 前后讲的连接、一个典型错法
（考试角度：A 级 Final 2025 Q4 / C 级 通识）

## 完整性对账
索引条目 87 条，全部出现：#L01-01 … #L15-06
```

- 开头第一行「修正过的条目：N 条」，按索引状态列数；N=0 时明写「修正过的条目：0 条」——从未修正过的记忆库不是干净，是遗忘机制没通电，写出来让用户看见。
- 费曼块五段顺序固定：capsule → 直觉 → 形式 → 算例 → 联系与误区；每块尾注 `#Lnn-kk` 与页码。块按讲次顺序排，不按主题重组（重组归重排入口）。
- 状态「待核」的条目在笔记里保留「待核」标记，不补页码。
- 完整性对账：索引每个 `#Lnn-kk` 都在笔记中出现，末尾列出编号清单；缺的补上，不静默丢。
- 考试角度沿用各讲伴读里的分级，不新造 A 级证据；无证据仍是 C 级措辞。
- 引用讲义原话仍用 `> **p.N**`，讲义没说的仍标「补充」。伴读里标「（非讲义内容）」的附录节与自取数字的算例，对账时不当讲义内容。

### 速查表（用户要 cheat sheet 时才写）

`study/速查表.md`，一行一条：`<结论 / 公式> — Lnn p.X — A/B/C`，按证据级别 A > B > C 排，同级按讲次；没有 prose。

## 重排入口

显式要求跨讲重组（「把流水线相关的三讲串成一篇」）时产出一份主题结构文档 `study/<主题>串讲.md`（H1 带课程代号）：按主题组织，每段引用各讲页码与 `#Lnn-kk`，只从记忆库与伴读取材，不重读 PDF。不改动任何已有伴读与记忆库文件、不合并或删除旧文件。

## 边界（本入口）

不出题、不做小测；缺讲不编内容；总结不「顺手」修正索引（修正只在跟课与用户明确指出时按 rules/memory.md 做）。
