# 排版与标注约定

目标：读者一眼分得清「老师的原话 / 我的讲解 / 我的补充 / 考试信息」，导出 PDF 后不丢信息。只用 markdown 稳定子集：不用下划线、HTML 标签、emoji 做任何标记。与 SKILL.md 压缩版冲突时以本文件为准。

## 引用讲义原话

blockquote，行首页码加粗，原文逐字（空白归一后与 pdftotext 一致），英文不翻译，一条引用一个 blockquote；翻译与讲解放在引用之后的正文里。页码 N 一律是 PDF 页号（`pdftotext -f N -l N` 翻到的页），不是讲义页脚的逻辑页号。

```markdown
> **p.4** What is the longest path (slowest instruction)? Load instruction!
```

blockquote 里不得意译、不得补全、不得把两句拼成一句。「speedup ≈ number of stages」这种改写放正文，不放 blockquote。一节里引用不超过讲解的三分之一；整页文字不整段引，引最能当锚的两三句，其余转述。

### 公式乱码（D1-A）

pdftotext 把分式拆成几行（本语料实测的形态：`z = logit(p) = ln ( p ) 1−p`）、把上下标摊平、或把字形抽成 `(cid:27)` 这类占位符（本语料 26 份 PDF 里没出现过，但别的讲义会）时：在 blockquote 里用 `$…$` 重排成讲义的公式，并在引用后的正文第一句注明「公式按讲义重排」。不把乱码补全成通顺英文原话，也不原样保留乱码。

```markdown
> **p.42** We define logit (a.k.a. log-odds) of an event A as $\mathrm{logit}(p)=\ln \mathrm{odds}(p)=\ln\frac{p}{1-p}$ whose range is $(-\infty,+\infty)$.

公式按讲义重排。……
```

数据通路、流水线时序这类结构图，能用表或 ASCII 画清楚就画，画不清楚就只描述，不硬画。只写「见图」= 没写。

**整页是一张位图时**（`pdftotext` 这一页只抽出一行标题，`pdfimages -list -f N -l N <pdf>` 显示一张占满版面的位图——CENG L11 p.16 就是这样）：先用 Read 工具直接读这一页（它能把 PDF 页渲染出来），照着看到的写「元素 / 看什么」三行。渲染不可用（工具读不了这个 PDF、或读回来看不清）时走第四条出路，写成一行并计进回复的「未识别」清单：

```markdown
图（p.16）：Memory Hierarchy Levels
本页正文为位图，无法读取图像内容
```

不许拿标题去推测图上画了什么——这一页宁可写「无法读取」，也不编元素。

## 字体标记

- `**粗体**`：术语首次定义处的中文术语；考试要能默写的结论句。合理使用，不设数量上限。
- `` `代码` ``：指令、寄存器、变量、机器码、文件名、任何要逐字符准确的东西（`lw x2, 4(x4)`、`0x00521133`、`ra`）。
- `*斜体*`：老师口语化的强调或提问的转述（*stay tuned*）。
- 术语首次「流水线（pipeline）」中英双写，之后任一；公式、代码、寄存器名、指令原样。
- 公式一律 `$…$` / `$$…$$` LaTeX，符号在公式后一句话定义。
- 三类标记用文字：【新】【延伸 L08 p.12】【已会】，只在概念首次出现的小节标题后。
- 证据级别用文字：（A 级：Final 2025 Q4.1）/（B 级：大纲）/（C 级 通识）。

## 伪代码

算法与过程性知识（冒险检测、cache 查找、搜索展开、梯度下降迭代）用围栏代码块，语言标 `text`，每行一步，不用真语言语法：

```text
for 每条指令 i：
  若 i 的源寄存器 == 上一条的目的寄存器且上一条是 load：插入 1 个 stall
  否则若能转发：标 →fwd
```

概念之间的**关系**（结构冒险 / 数据冒险 / 控制冒险）不用伪代码，用缩进列表；mermaid 仅在导出目标支持时用，否则退回缩进列表。
