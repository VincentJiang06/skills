- 【公式不渲染类，来源：v4.1 对 39 份真实产物的全量扫描（2026-09-14）】同一批产物里按条数排下来的前四种写法，全都在 Typora 里出问题，全都是「自己读着没事、渲染出来是另一回事」：① **单行 `$$…$$`**（221 处，最多的一种）——`$$` 要各自独占一行、块前块后留空行，否则整块塌成正文。② **公式里出现非 ASCII 字符**（62 处，多半是 `p_{\text{对}}` 这种往 `\text{}` 里塞中文，还有裸的 `×` `≤` `Δ`）——公式内一律全 ASCII，中文注解挪到公式外面。③ **标题或文件头里写公式**（59 处）——`#` 标题行与文件头引用块都不出现 `$`，公式挪进正文。④ **行内写 `\begin{pmatrix}`**（20 处）——环境只能待在 `$$` 块里，行内的 `\\` 会被当成转义。另有公式里的裸竖线上百处（`P(\hat y=1|X)` 这类），落到表格单元里的 8 处会被表格解析器当列分隔符吃掉，一律写 `\mid`。处置：不是「渲染不出来再回头改」，是写的时候就按 rules/format.md 那十一条写，每节写完自查一遍。

三条**讲解层错误**（来源：Codex 终审在 L12 真实产物上逐句核到，2026-09-14）。共同点：讲义原句都在手边，写的人没回去看那一句，凭直觉补了一个机制方向或一个因果，形状全部合格、扫描器全绿。

- 【机制方向写反，锚：L12 p.13–14】产物写「C=0 左 latch 透明、右 latch 关闭；C=1 反过来」。讲义 p.13 逐字是 `Set Q = D when C = 1.` 与 `When C = 0, the AND gate ensures that R = S = 0, Q does not change.`；p.14 逐字是 `At T=0, the first D latch sees C=0, and locks D value in its output Q.`、`At T=t, the second D latch sees C=1 (inverted)`。代 C=0 进 p.13 那句：第一个 latch **锁住**，看到反相 C 的第二个才透明——产物把两侧写反了。正确处置：主从结构这种「谁在什么电平打开」的话，回到那两页把这三句抄出来再写；同页还有「稳态下总有一侧被挡住」（`In stable state ... one ... is blocked`），它只说稳态，不能扩写成「任何时刻都不会同时透明」。
- 【行列混淆，锚：L12 p.20–21】产物写「两级译码把阵列行数从 4M 减到 4K，所以字线更短」。讲义 p.20 逐字 `Each row is an entry (block).`，p.21 逐字 `Break a 4M×8 SRAM into 8 4K×1024 SRAMs.`、`select one row (1024-bit) from each SRAM array.`：拆分后每行从 8 bit 变成 1024 bit，每列上挂的行数从 4M 降到 4K。行数变少 ≠ 字线变短（字线是沿着一行走的，行反而变宽），而且讲义根本没给布线尺寸。正确处置：数值照算，物理解释只写讲义页上写了的那一层；要说长度就得有页上给的尺寸。
- 【来源越界，锚：L12 p.19 与 p.23】两例。① 产物写「十进制 2M 与二进制 2Mi 的差决定要不要多一根地址线」；讲义 p.19 只有 `2M x 16 has 2 × 10^6 entries (16-bit), total 4MB.` 与 `Address requires log₂ P bits.`，代进去 ceil(log₂ 2,000,000)=21、log₂ 2,097,152=21，地址线**一样多**，这个因果是自己加的。② 产物把 `The refresh operation becomes transparent to the users.`（p.23）扩写成「外面的内存控制器不用操心何时刷新」；讲义没说 users 指控制器，也没交代刷新命令由谁发起。正确处置：讲义只说到哪一步就写到哪一步，再往前一步的推论标「**补充**：」并用不确定语气（细则见 rules/companion.md §5 机制类陈述那一条）。

v4.2 追加（来源：真实课程文件夹里的退化产物 `CSCI3230/study/L04-P2-Support-vector-machine.md` 与 O-9 / O-9a 裁决，2026-09-17）。对应的正例见 rules/exemplars.md 第二段。

- 【正确而浓缩不是讲透，锚：L04 p.22–24】退化产物整节只有三四句：「间隔为 2/‖w‖，最大化间隔等价于最小化 ½‖w‖²，约束为……」。每句都对，但 w 是什么、2 从哪来、为什么多个平方、约束里的 1 谁定的，全没答，也没有数字。判据不是对不对，是没听课的人读完能不能复述、换个数能不能重算。
